# 2.0.0 发布前验收

2026-09-09。当前为候选版本，尚未发布。本文只描述最终保留的功能，旧界面过程记录存放于本地验收产物。

## 最终范围

- Codex 订阅登录、多账号切换、额度、搜索、模型配置、诊断及异常恢复。
- 设置分为“账号与偏好”和“高级与诊断”；图片功能在高级页按三组控制。
- 输入框支持百分比、进度条、续航预测和关闭。存在 5 小时窗口时仅显示短窗口，周额度保留在详情；单周进度条无文字。无时钟图标、无冗长预测说明，数字仍为官方读数。
- 预测保留 Beta：区间约束足够时显示范围；至少 5 分钟、3 个新鲜样本和 1 个百分点下降时可提供近期平均初步估计，界面以 ≈ 表示。不能视为实际工作时间保证。
- 自然语言生图、明确参考图编辑、@Image / @生图原位指令、单独草图按钮及 @Sketch。草图保留 Beta，支持三种笔刷、两种橡皮、基础图层和撤销重做。
- 生成图片在工具折叠区外展示，历史回放保留；粘贴和历史图片可打开增强预览、标注后回到输入框。关闭增强时恢复宿主预览。
- 不包含图片库、模板、并排比较或第二个生成窗口。标注不是像素 mask。
- Flare / Sunburst 保留实验选项：请求成功出图，但指定型号、质量实际是否生效无法确认，不静默切换型号。

## 实机证据

本地路径 `.artifacts/capability-audit/`，使用安装包后的官方 DSH 页面，通过本机无头 Chrome 操作并查看截图。模拟数据不计作真实账号生图或预测准确率证明。

- `device-cancel-acceptance.cjs`、`device-cancel-signed-out.cjs`：设备码登录取消、已有账号保留、未登录入口恢复，以及迟到状态不复活已取消流程；登录请求为模拟数据。
- `enhanced-preview-acceptance.json`：真实浏览器粘贴、预览、标注、下载、返回输入框、拖放与移除、窄屏操作。
- `layer-workspace-acceptance.json`：真实 canvas 像素、图层显隐/顺序/复制/重命名/删除、两种橡皮和撤销重做。
- `output-node-acceptance.cjs`：已有真实生成结果无需展开工具即可见，预览及刷新回放成功；亮暗草图截图已查看。
- `two-new-model-events.json`：Luna 分别传入 GPT Image 2、Flare、Sunburst 后成功出图。实际型号未报告；不能证明指定型号或质量有效。
- `release-final-quota.cjs`、`release-final-quota.png`：最终 5h 优先、无图标、待估与 ≈ 时间、所有窗口详情均通过，脚本正常退出且未修改用户设置。
- `release-reviewed-tests.txt`：326 通过、3 跳过、0 失败。`release-alpha-inspection.txt`：最终包在 0.1.5-alpha.1 登录入口及设置正常加载。

## 发布边界

- 正式宿主基线为 0.1.2-rc.1，0.1.5-alpha.1 为预览兼容。
- 390px 宿主设置外壳仍可能挤压侧栏后的内容；不能宣称整个设置页已完成手机适配。草图、预览的窄屏检查不替代设置页检查。
- 预测没有长期准确率评估，继续保留 Beta。双窗口精度联动、工作习惯预测、原生子代理集成属于后续研究，不计入 2.0.0 已交付能力。
- README 和公开演示保留已发布版本内容；正式上线后再按最终界面更新。
