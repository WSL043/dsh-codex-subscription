# 2.0.0 发布前验收

2026-09-09。用户已完成交互验收并授权发布 2.0.0；发布结果以 GitHub Release 与 npm 为准。本文只描述最终保留的功能，旧界面过程记录存放于本地验收产物。

## 最终范围

- Codex 订阅登录、多账号切换、额度、搜索、模型配置、诊断及异常恢复。
- 设置分为“账号与偏好”和“高级与诊断”；图片功能在高级页按三组控制。
- 输入框支持百分比、进度条、续航预测和关闭。存在 5 小时窗口时仅显示短窗口，周额度保留在详情；单周窗口不显示“周”前缀，小时使用 h。无时钟图标、无冗长预测说明，数字仍为官方读数。
- 预测保留 Beta：区间约束足够时显示范围；至少 5 分钟、3 个新鲜样本和 1 个百分点下降时可提供近期平均初步估计，界面以 ≈ 表示。不能视为实际工作时间保证。
- 自然语言生图、明确参考图编辑、@Image / @生图原位指令、单独草图按钮及 @Sketch。草图保留 Beta，支持三种笔刷、两种橡皮、基础图层和撤销重做。
- 生成图片在工具折叠区外展示，历史回放保留；粘贴和历史图片可打开增强预览、标注后回到输入框。关闭增强时恢复宿主预览。
- 不包含图片库、模板、并排比较或第二个生成窗口。标注不是像素 mask。
- Flare / Sunburst 保留实验选项：请求成功出图，但指定型号、质量实际是否生效无法确认，不静默切换型号。

## 发布边界

- 正式宿主基线为 0.1.2-rc.1，0.1.5-alpha.1 为预览兼容。
- 390px 宿主设置外壳仍可能挤压侧栏后的内容；不能宣称整个设置页已完成手机适配。草图、预览的窄屏检查不替代设置页检查。
- 预测没有长期准确率评估，继续保留 Beta。双窗口精度联动、工作习惯预测、原生子代理集成属于后续研究，不计入 2.0.0 已交付能力。
- README 和公开演示保留已发布版本内容；正式上线后再按最终界面更新。

## 最终交互与性能验收

- `sketch-tools-acceptance.cjs`：多草稿、刷新恢复、导入图片图层、撤销重做。草稿仅存在当前浏览器，最多 20 份，并限制总存储大小。
- `sketch-path-acceptance.cjs`：图片进入草图、图片图层管理、缩放拖动、可配置快捷键与关闭；平滑只在抬笔后处理，按住鼠标时不修改路径。
- `sketch-dismiss-acceptance.cjs`：浮层外部点击和 Esc 关闭，不误画点；圆形光标匹配笔宽、铅笔系数和视图缩放。
- `sketch-installed-performance.json`：8 个图层、352000 个历史采样点加图片背景；持续绘画未出现超过 50ms 的主线程长任务，帧间隔与该无头浏览器的空闲基线一致。不能推广为所有设备绝不卡顿。
- `sketch-perf-final.json`：增量追加、撤销、橡皮与完整重绘逐像素一致；极端画稿初次重建与持续绘画开销分别记录。
- `native-attachments-acceptance.cjs`：复用宿主原生附件组件、样式和拖放逻辑；插件仅增强打开预览，保留原生删除与已有草稿。
- `quota-shared-offset-replay.json`：同一真实记录下，保守范围约 8.2–18.2h，共享取整偏移假设约 10.5–12.5h；不是预测准确率证明。细化要求至少三次跳格、20 分钟、整数且单调的读数，并保留两分钟更新延迟容差；假设不成立则退回保守估算。预测仍为 Beta。
