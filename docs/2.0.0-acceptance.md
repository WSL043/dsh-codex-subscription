## 本轮交付

- 整体模块整理：账号、模型选择、额度、偏好、诊断分别维护；入口负责组装。服务端 RPC 路由、通信与配置契约独立，凭据和网络边界保留。详见 [架构](2.0.0-architecture.md)。
- `@Sketch` 和统一图片菜单中的草图入口；画笔、矩形、椭圆、橡皮擦、粗细、颜色、撤销/重做，导出为附件。大画布、浮动工具栏和圆形色板按用户提供的设计参考重新打磨。
- `@生图` / `@Image` 打开简短创作面板，保留自然语言生图；仅更新草稿，由用户发送。快捷入口独立开关，同时停用生成与编辑时卸载图片工具，减少后续工具目录上下文。
- 海报、商品图、图标模板填入可编辑草稿；会话图片库最多展示 100 张生成图，可选最多 5 张原图作为一次编辑的参考、选择两张并排比较。
- 设置按“图片生成与编辑”“创作入口”“图片浏览”三组管理，旧的混合设置在主动更改前保留。模型和质量可单独设置；默认仍为 GPT Image 2。
- 2.5 Flare / Sunburst 实验模型标识和质量参数校验；不自动换型号重试。

## 异常恢复与额度预测

设置合并为账号与偏好、高级与诊断两页。单周额度条隐藏周期文字，展开仍显示完整信息。故障注入在隔离浏览器拦截 DSH HTTP RPC 响应：状态读取失败、重试再次失败、清除前确认、模拟清除后登录入口及服务端诊断失败后的本地报告均通过；没有清除真实账号。单元测试另外验证损坏凭据可直接删除、请求超时会终止等待，见 `recovery-browser.json`。

额度提醒使用 18% 剩余／20% 阈值的测试响应，在额度卡显示具体说明，当前模型额度条变色且展开提示；恢复到 80% 后提示消失。截图明确标注测试数据，见 `quota-alert-browser.json`、`quota-alert-test-2.0.png`。测试后恢复原偏好。本机真实诊断接口及深浅主题设置检查通过。

预测改用最近两小时，修复空值重置时间误判、缓存重复采样，拒绝旧数据；长断档和明显速度变化重新校准，详情显示包含量化误差的估计范围。稳定、突增、断档和旧数据样本测试通过，但尚无长期真实误差回放，因此保留 Beta，不声称已证明预测准确率。此轮全套 316 通过、3 跳过。未发布。
