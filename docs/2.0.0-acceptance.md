# 2.0.0 候选版验收

日期：2026-09-09。**未发布；需要用户验收后才能发布。** 本文将已做验证与未覆盖能力分开记录，不把源码测试当成所有账号、所有型号的实机证明。

## 本轮交付

- 整体模块整理：账号、模型选择、额度、偏好、诊断分别维护；入口负责组装。服务端 RPC 路由、通信与配置契约独立，凭据和网络边界保留。详见 [架构](2.0.0-architecture.md)。
- `@Sketch` 和输入框草图按钮；画笔、矩形、椭圆、橡皮擦、粗细、颜色、撤销/重做，导出为附件。大画布、浮动工具栏和圆形色板按用户提供的设计参考重新打磨。
- `@生图` / `@Image` 打开简短创作面板，保留自然语言生图；仅更新草稿，由用户发送。快捷入口独立开关，同时停用生成与编辑时卸载图片工具，减少后续工具目录上下文。
- 海报、商品图、图标模板填入可编辑草稿；会话图片库最多展示 100 张生成图，可选最多 5 张原图作为一次编辑的参考、选择两张并排比较。
- 图片生成、编辑、查看、编号评论、草图、模板、图库、对比分别可开关。模型和质量可单独设置；默认仍为 GPT Image 2。
- 2.5 Flare / Sunburst 实验模型标识和质量参数校验；不自动换型号重试。

## 尚未覆盖

- Sunburst 未实测；Flare 编辑及其他对话模型逐一调用未实测；不保证其他订阅账号的型号可用性。
- alpha 通道完成设置/通信验收，未复制登录凭据或在 alpha 上执行付费生图。
- 真正的像素 mask、原图自由涂画编辑、流式部分帧、非 PNG 输出尚未实现。编号评论和空白草图不是 mask。没有加入无限图片历史或自动推断父子版本树。
- 2.0 正式宿主基线是 0.1.2-rc.1；旧版缺少新的官方精确路由接口，需升级宿主或保留插件 1.x。

## 用户验收

本机已登录验收入口：`http://127.0.0.1:58681/`。

1. 正常聊天，查看模型菜单、额度和订阅设置，确认原有习惯没有被打断。
2. 输入 `@生图` 填写创作说明，或输入 `@Sketch` 绘图、切换颜色、撤销/重做，确认后检查草稿及附件，再手动发送。
3. 在既有生成图片会话打开图片库，选择两张对比或附加编辑；确认原图查看和下载体验。
4. 在“图片工作台”分别开关功能，检查入口和执行行为；选择实验模型时注意账号可用性。
5. 确认桌面与窄屏视觉、文案、操作后再决定发布。当前没有创建发布标签或上传 npm。

包体和入口行数的对照保存在 `2.0-size-report.json`；新增功能没有引入新的运行时依赖，但增加了客户端包体，不将模块拆分宣传为下载体积缩小。
