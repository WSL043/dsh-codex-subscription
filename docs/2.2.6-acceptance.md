# 2.2.6 acceptance notes

Real ChatGPT account, the packed 2.2.6 candidate, isolated DSH hosts on `0.2.0-rc.1` and `0.1.7-rc.2`. Image requests used low quality and a single small image each.

## Defect found and fixed

Generated images were never visible in the conversation on either host: the tool row showed only the "Image details" text.

- Cause 1: the host delivers a settled tool result's rendered blocks directly in `message.content` (`[text, image]`). The conversation node only looked for a wrapped `tool-result` block, so it never matched. Its unit tests used the wrapped shape, which the host does not produce.
- Cause 2: the host folds every custom conversation node into a process group that stays collapsed after the turn completes, and only its own node kinds are exempt. The public node contract has no way to opt out.
- Fix: the node now accepts the real event shape, and the tool row itself renders the image (with the viewer, download and continue-editing actions). Expanding the tool call shows the picture on both hosts.
