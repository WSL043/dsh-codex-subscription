# 2.4.0 acceptance, 2026-09-30

Official DeepSeek Harness desktop app 0.2.0-rc.2 (Windows x64), isolated data directory, real ChatGPT account. The 2.4.0 build was copied over an installed 2.3.0 and the app restarted, so these are the published sources, not a dev server.

## SVG drawing command

| Check | Result |
| --- | --- |
| The model picks the new command on its own: the lighthouse run used 8 `codex_sketch` calls, 6 of them `svg` batches (the model's own account of the run) | pass |
| Result stays native: 6 layers, 229 editable strokes, undo works (two stray pen dots from a mis-click were undone) | pass |
| Same lighthouse prompt, GPT-6.1-Sol Xhigh: about 19 minutes before the change, about 13 minutes with it | one run each, indicative only |
| Clock tower (9 meshing gears, pendulum, staircase) and blue-green landscape drawn by Sol Xhigh and Astra Low, each followed by one GPT Image 2 call | pass, images in the README |

Not covered: a side-by-side of the same scene drawn with and without SVG on the same model, very large SVG documents near the 200000-character limit.

## Other fixes found during the run

| Finding | Fix |
| --- | --- |
| Sol's first image call on the clock tower failed with only "Codex image edit request failed" | Network failures now name the transport error (timeout, reset, DNS) with a bounded code; the retry succeeded |
| On the desktop app the Codex subtask component was never detected, because the plugin could not resolve the host's bundled packages from the profile folder | The host version is also resolved from the host entry script; the component now installs as 0.2.0-rc.2 and is detected after a restart |
| The short diagnostics report put the plugin client version in the `dsh` field | It now reports the real DSH version and the platform |
| Diagnostics findings used a larger font than the rest of the card | Aligned to 13px |
| The storefront `screenshots.json` listed the same two pages in two languages | Seven different pages: account, composer, models, images, sketch board, two sketch results |

Not covered on the desktop app: running a Codex subtask end to end (component detection only), WebSocket, cloud compaction.
