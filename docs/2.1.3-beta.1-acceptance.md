# 2.1.3-beta.1 验收记录

日期：2026-09-19。该版本以 DSH 兼容性和已有功能可靠性为主，没有新增运行时依赖。

## 实现

- 开发基线更新到 DSH 0.1.5-rc.2，增加 0.1.6-alpha.2 兼容声明。
- 图片异步回填在新宿主中保有会话引用，完成或失败后释放；导航使用 uiWorkspace.openSession，旧宿主保留 sessions.open 路径。
- 同一会话存在多个视图时分别登记草图入口，关闭其中一个不会丢失另一个入口。
- 插件卸载时关闭预览、清理草图入口并中止未完成的图片读取。
- 增强图片预览遵守宿主 compact、thumbnail 和 label 参数。
- 成功切换、移除或退出账号时清理已有连接；失败操作和读取状态不触发清理。
- 离线模型目录不再回填已退役的 Spark；在线目录仍由官方决定，GPT-5.5 不提前移除。

## 已完成验证

- rc.2 开发环境完整测试：444 通过，3 个条件性跳过，0 失败。
- alpha.2 / pi-ai 0.85.1 原生行为回归：339 通过，0 失败。
- 最终构建包安装到独立 DSH_HOME；安装后 client.js 与本地最终构建 SHA-256 一致。
- alpha.2 浏览器实测：设置默认值、草图绘制、附加草图、草稿图片预览返回、会话图片回填。返回原会话成功，已输入文本保留，没有自动发送。
- 在安装后的 alpha.2 页面用 Luna 发送蓝色测试笔画，实际回复“蓝色”。
- alpha.2 适配器真实 Luna 请求：普通回复、工具结果往返、WebSocket 选项请求均成功。后者允许原生 SSE 回退，不证明本次一定使用了 WebSocket，也不代表性能提升。
- Luna 云端压缩：约 52 KB 合成文本获得压缩状态，写入原生 JSONL，由新进程读回后携带 compaction 项继续请求。正确返回 ORBIT-618、7300 元、2026-11-23、禁止覆盖原稿；继续请求输入约 9.5 KB。这不是通用质量或速度基准。

## 边界与保留项

- 云端压缩、WebSocket、独立 Codex 子任务、草图仍为自愿开启的 Beta；不修改默认行为，不用一次验收替代长期稳定性判断。
- 官方额度历史端点当前账户实测 HTTP 404，未加入产品开关或轮询。
- 不替换 DSH 官方子代理内置的 Codex 版本，不复制它的任务控制器。
- 多视图入口和账号连接清理已做针对性回归；没有宣称所有多窗口/多账号组合都完成真实账户操作。
- 隔离宿主重启时观察到 DSH 自身 inspect/inventory 接口的取消与短暂重连错误；本轮图片操作完成，不将这些旧日志当成插件操作失败或宣称整个 alpha 宿主无错误。
- 浏览器验收使用 DSH 官方 browse 目录选择器配置，避免操作桌面原生文件夹窗口；用户安装配置未更改。

上游研究依据见 [审计记录](upstream-audit-2026-09-19.md)。发布流程另行验证 Windows 安装管理脚本和 latest/alpha 的安装、运行、更新、移除。
