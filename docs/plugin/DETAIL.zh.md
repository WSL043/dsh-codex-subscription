先在下方「开始」登录 ChatGPT，再从会话输入栏选择 Codex 模型。本页与「设置 → Codex 订阅」共用配置。

### 功能与设置位置

- **开始** — 管理登录账号，查看剩余额度、重置时间与用量预测，设置输入栏的额度显示。
- **模型** — 选择显示的模型、推理等级、响应速度和回答详略，调整输入栏的模型菜单与速度入口。
- **联网与工具** — 选择搜索和网页获取的提供方，设置 ChatGPT 连接器和子任务的执行方式。
- **创作** — 生成或编辑图片，使用会话附件和可读取的本地图片作为参考，添加图片评论针，或使用草图画板。
- **手机与更多** — 开启语音对话、从 ChatGPT App 远程连接 DSH，查看连接状态和支持诊断。

### 费用与使用条件

- 普通 Codex 对话使用 ChatGPT 订阅，无需 OpenAI API Key。搜索与网页获取分别选择提供方；Codex 选项使用订阅服务，DeepSeek Search / Fetch API 按其 API 规则计费，HTTP 使用 DSH 的常规网页获取。
- 只有选择官方 Codex 子智能体后端时才需要对应 CLI 部件。通过 DSH 插件页管理该部件；普通对话、搜索和生图无需额外安装 Codex CLI。
- 生图时可以让模型读取有权限访问的本地图片作为参考。图片评论针在关闭查看器时保存，点击「添加到输入框」才会带入修改指令。
- 额度预测基于已保存的用量记录，会随使用节奏和其他设备的用量变化。Beta 选项需手动启用，可用性取决于账号和平台。
