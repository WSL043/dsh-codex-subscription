Inicia sesión en ChatGPT en **Inicio** y elige un modelo Codex en el cuadro de conversación. Esta página comparte la configuración con **Ajustes → Suscripción de Codex**.

### Funciones y dónde encontrarlas

- **Inicio** — Cuentas, cuota restante, fecha de restablecimiento, previsiones y visualización de cuota en el cuadro de entrada.
- **Modelos** — Modelos visibles, esfuerzo de razonamiento, velocidad, detalle de las respuestas, menú y acceso rápido de velocidad.
- **Web y herramientas** — Proveedores de búsqueda y lectura de páginas, conectores de ChatGPT y ejecución de subtareas.
- **Crear** — Generación y edición con imágenes adjuntas o archivos locales como referencias, comentarios sobre imágenes y lienzo de dibujo.
- **Teléfono y más** — Conversaciones de voz, acceso remoto desde la App de ChatGPT, estado de conexión y diagnóstico.

### Costes y requisitos

- Las conversaciones Codex utilizan tu suscripción de ChatGPT sin clave API de OpenAI. La búsqueda y la lectura de páginas tienen proveedores independientes. Codex usa la suscripción; DeepSeek Search / Fetch API aplica sus tarifas API; HTTP usa la lectura habitual de DSH.
- El backend oficial de subagentes Codex necesita su componente CLI, gestionado desde Plugins de DSH. El chat, las búsquedas y las imágenes no requieren instalar Codex CLI por separado.
- El modelo puede leer imágenes locales a las que tenga acceso. Al cerrar el visor se guardan los comentarios. **Añadir al cuadro de entrada** incorpora sus instrucciones de edición al cuadro de conversación.
- Las previsiones usan el historial guardado y varían con tu ritmo y el uso en otros dispositivos. Las opciones Beta deben activarse y dependen de la cuenta y la plataforma.
