Войдите в ChatGPT на вкладке **Начало**, затем выберите модель Codex в поле ввода. Эта страница использует те же настройки, что и **Настройки → Подписка Codex**.

### Возможности и настройки

- **Начало** — Аккаунты, остаток лимита, время сброса, прогноз и отображение лимита в поле ввода.
- **Модели** — Видимые модели, уровень рассуждений, скорость, подробность ответа, меню моделей и переключатель скорости.
- **Веб и инструменты** — Сервисы поиска и загрузки страниц, подключённые приложения ChatGPT и выполнение подзадач.
- **Создание** — Генерация и редактирование изображений с вложениями или локальными файлами как образцами, комментарии на изображениях и холст.
- **Телефон и другое** — Голосовые разговоры, удалённое подключение через приложение ChatGPT, состояние связи и диагностика.

### Оплата и условия

- Разговоры Codex используют подписку ChatGPT без API-ключа OpenAI. Поиск и загрузка страниц имеют отдельные настройки сервиса. Codex использует подписку; DeepSeek Search / Fetch API оплачивается по правилам соответствующего API; HTTP использует обычную загрузку страниц DSH.
- Официальный backend подагентов Codex требует компонент CLI, которым управляет страница плагинов DSH. Для чата, поиска и генерации изображений дополнительная установка Codex CLI не требуется.
- Модель может читать доступные ей локальные изображения. При закрытии просмотрщика комментарии сохраняются. **Добавить в поле ввода** переносит инструкции редактирования в разговор.
- Прогноз строится по сохранённой истории и зависит от темпа использования и других устройств. Опции Beta нужно включить; доступность зависит от аккаунта и платформы.
