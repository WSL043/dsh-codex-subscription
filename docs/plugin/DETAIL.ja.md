下の **はじめに**で ChatGPT にログインし、会話の入力欄で Codex モデルを選んでください。このページと **設定 → Codex サブスクリプション**は同じ設定を使います。

### できること・設定場所

- **はじめに** — ログインするアカウント、残りの利用枠、リセット日時、利用枠予測、入力欄の利用枠表示。
- **モデル** — 表示するモデル、推論強度、応答速度、回答の詳しさ、入力欄のモデルメニューと速度切り替え。
- **Web とツール** — 検索・ページ取得の提供元、ChatGPT の接続アプリ、子タスクの実行方法。
- **作成** — 画像の生成・編集、会話の添付画像や読み取り可能なローカル画像の参照、画像へのコメントピン、スケッチ画板。
- **スマートフォン・その他** — 音声会話、ChatGPT App から DSH への遠隔接続、接続状態とサポート診断。

### 料金・利用条件

- 通常の Codex 会話は ChatGPT のサブスクリプションを使い、OpenAI API キーは不要です。検索とページ取得は個別に提供元を選べます。Codex は購読サービス、DeepSeek Search / Fetch API は各 API の課金規則、HTTP は DSH の通常のページ取得を使います。
- 公式 Codex 子エージェントを選ぶ場合は CLI 部品が必要です。部品は DSH のプラグインページで管理します。通常の会話・検索・画像生成には追加の Codex CLI インストールは不要です。
- 画像ビューアを閉じるとコメントピンを保存します。**入力欄に追加**で編集指示を入力欄に送れます。
- 利用枠予測は保存した使用履歴に基づく目安です。他端末の利用でも変わります。Beta 機能の利用可否はアカウントや環境によって異なります。
