# 2.0.0 模块与维护边界

入口只组装宿主服务、RPC 与客户端组件。凭据和订阅请求留在 DSH 主机，不读取 Codex CLI 登录，也不引入 API Key 后备。

| 模块 | 职责 |
| --- | --- |
| client-account.jsx / login-coordinator.js | 账号界面与可取消的主机登录流程；过期客户端轮询不得恢复旧登录 |
| quota-forecast.js / quota-rate-interval.js / quota-forecast-store.js | 官方快照的账号和额度池隔离、区间估算、有限历史持久化 |
| client-composer-quota.jsx | 输入框紧凑显示及完整窗口详情，不改变官方额度数值 |
| codex-images.js / image-models.js | 生成编辑请求、原图校验、显式型号和参数校验 |
| image-conversation-node.js | 从已有工具结果构建会话视图，不额外插入模型上下文 |
| client-image-previews.jsx / client-images.jsx | 原生附件展示入口、预览与编辑回填 |
| sketch-studio.jsx / sketch-document.js / sketch-styles.js | 笔画、图层、撤销与导出；使用宿主亮暗色彩 |
| image-features.js / image-setting-groups.js | 运行时开关与旧细分设置兼容 |

图片生成和编辑关闭时撤销工具注册；已有结果继续可查看。所有附件回填共用宿主接收和失败清理路径。草图只产生附件，不自动发送。已发送给官方的生成请求不能承诺取消。

图片库、创作模板及比较功能已移除。新的功能不得再次引入对整个宿主历史和附件管理的接管。

2.5 型号参数保留实验标签，未知返回字段不得用请求参数冒充。普通会话模型与图片引擎独立。

每次发版重建 lib 并核对实际安装包；预览宿主的设置验证不能推广为所有付费能力均已实测。模块拆分不等于下载体积缩小。
